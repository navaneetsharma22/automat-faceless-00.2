## Changes

- Desktop Images workspace uses a 60/40 weighted grid with a width-aware queue minimum and a taller source editor.
- Images workspace removes the independently scrolling outer queue column. The prompt list is the bounded scroll surface, leaving its status and actions visible above it. The editor retains its own scrolling for long JSON.
- The existing compact Wrap lines / Expand editor toolbar, responsive source action toolbar, validation/save step grouping, compact prompt rows, and full-width Source summary presentation are retained.
- Queue cards compact their status summary, countdown, action area, and shot rows while keeping prompt content, Shot IDs, statuses, dispatch receipt/raw prompt inspection, and technical details available.

No queue, parser, storage, connection, dispatch, receipt, timer, retry, recovery, or confirmation handler was changed. No behavior difference identified by source review or focused local tests.
