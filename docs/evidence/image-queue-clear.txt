# Image queue “Clear existing prompt” evidence — 8 November 2026

## Scope

Implemented the requested clear action for a blocked queue in the current Automat Faceless Image panel. The action is available only on a blocked queue card and opens a native confirmation dialog with the requested title, message, and Cancel / Clear existing prompt actions.

Confirmation calls the existing `imageQueue.stop` lifecycle operation with the selected queue ID and the revision shown by that queue card. The repository transition saves and reads back the stopped revision; the scheduler's existing stop handler clears that queue's alarm. Sent receipts and item outcome evidence remain in the queue record. Stop is terminal, so the old queue cannot be started again. A stopped queue with preserved uncertain delivery evidence no longer blocks a distinct new source; exact-source duplicate locking remains in force. The editor draft is cleared only when its exact source text matches the queue that was retired.
